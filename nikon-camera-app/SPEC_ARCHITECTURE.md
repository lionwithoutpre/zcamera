## 2. 双通道机制

```
                    ┌──────────────────┐
                    │  连接优先级决策器   │
                    └────────┬─────────┘
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
     ┌────────────────┐ ┌────────────────────────┐
     │  有线通道 (USB) │ │   无线通道 (Wi-Fi)      │
     │  • USB-OTG     │ │  • 尼康 SnapBridge     │
     │  • 最高优先级   │ │  • 备用/降级方案         │
     │  • 零拷贝传输   │ │  • HTTP 轮询 (keep-alive)│
     │  • 实时控制     │ │  • 低功耗模式           │
     └────────────────┘ └────────────────────────┘
```

### 2.1 适配器工厂

```c
// USB PTP 适配器
CameraAdapter *adapter_create_ptp(PtpSession *session);

// Wi-Fi 适配器 (独立 NikonWiFiCtx, 独立 kNikonWiFiVtable)
CameraAdapter *adapter_create_wifi(const char *ip_addr, uint16_t port);

// 注入外部 PtpSession 到 Wi-Fi 适配器
void adapter_wifi_set_session(CameraAdapter *adapter, PtpSession *session);
```

### 2.2 会话参数化

```c
// PtpSession 初始化需指定传输层参数 (不再硬编码)
int ptp_session_init(PtpSession *session, int fd,
                     PtpTransport transport, uint8_t ep_out, uint8_t ep_in);

// 托管会话 (含心跳线程 + 重连回调)
ManagedSession *managed_session_create(int fd, PtpTransport transport,
                                        uint8_t ep_out, uint8_t ep_in);
void managed_session_set_reconnect_cb(ManagedSession *ms,
                                       session_reconnect_cb cb,
                                       void *user_data);
```

## 3. 事件系统架构

```
┌─────────────────────────────┐
│      拍摄事件源              │
│  ┌───────────────────────┐  │
│  │ 通道A: PTP Event Poll │  │  ← USB 连接 (首选, 50~200ms 自适应)
│  │ 通道B: inotify DCIM   │  │  ← USB MTP 模式 (备选, Linux)
│  │ 通道C: HTTP 轮询      │  │  ← Wi-Fi 连接 (备用, 1000ms)
│  └──────────┬────────────┘  │
└─────────────┼───────────────┘
              ▼
┌─────────────────────────────┐
│   EventWatcher (统一监听器)  │
│  • 事件去重 (2s 窗口, 32条)  │
│  • HTTP 错误连续≥3次→ERROR  │
│  • _Atomic running 线程安全  │
│  • keep-alive 持久连接       │
└─────────────────────────────┘
```

## 4. 传输引擎架构

```
┌──────────────────────────────────────┐
│         TransferEngine               │
│  • 线程池 (最多 16 工作线程)          │
│  • 任务队列 (FIFO + 条件变量)         │
│  • 自适应块大小 (64KB~4MB)           │
│  • 断点续传 (检查 dest 文件已有大小)   │
│  • 重试机制 (3次, 间隔 500ms)         │
│  • _Atomic cancelled/running/initialized │
└──────────────────────────────────────┘
```

## 5. 核心性能指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 连接建立时间 | < 3s | USB 枚举 + PTP 会话建立 |
| 拍照事件延迟 | < 100ms | 从按下快门到 APP 感知 |
| 传输速度 (USB) | > 30MB/s | 零拷贝 + 分块并发 |
| 传输速度 (Wi-Fi) | > 5MB/s | HTTP 流式传输 |
| 断点续传效率 | > 95% | 失败后断点恢复成功率 |
| 内存峰值 | < 200MB | 大文件分块避免 OOM |
| 电池消耗 (Wi-Fi) | < 5%/h | 优化轮询间隔 |
